# 周纲 Stevenson · 律师个人网站

一个纯静态个人网站，无需安装依赖、无需构建步骤，直接用浏览器打开 `index.html` 即可查看。

## 页面结构

| 页面 | 内容 |
|---|---|
| `index.html` | 首页：个人介绍、三大核心业务、服务流程、专业优势 |
| `about.html` | 个人简介：执业方向、教育背景、工作语言、工作方式 |
| `practice.html` | 专业领域：外企直接投资、中企跨境投资、国际贸易的服务清单 |
| `works.html` | 专业作品：文章 / 研究成果 / 代表业绩 / 分享活动 |
| `contact.html` | 联系方式、咨询前准备、常见问题 |

共享资源位于 `assets/`：`css/style.css`（样式）、`js/main.js`（交互）、`img/`（图片）。

## 本地预览

直接双击 `index.html`，或在本目录启动一个静态服务器后访问本机地址。**本机地址仅供自己预览**，他人无法访问；对外访问需通过 EdgeOne 等平台发布后的公网链接。

## 发布链路

```
本地文件 → GitHub 私有仓库 my-website (main 分支) → EdgeOne 自动部署 → 公网 https 链接
```

EdgeOne 项目构建配置（纯静态站点）：

- 安装命令：留空
- 构建命令：留空
- 输出目录：`./`
- 生产分支：`main`

## 每次修改内容后

```bash
git add -A
git commit -m "Update: 本次改动说明"
git push origin main
```

推送后 EdgeOne 会自动重新部署，无需再到控制台手动操作。
